# TRADING · laboratorio de análisis de mercado

Cuaderno exploratorio con descarga de series mediante `yfinance`, indicadores y visualizaciones interactivas. El repositorio contiene el cuaderno `TRADING.ipynb`; no incluye un motor de ejecución de órdenes ni el bot que pueda operar en otros entornos.

Abrir en Jupyter con `pandas`, `numpy`, `yfinance`, `scikit-learn`, `matplotlib`, `mplfinance`, `plotly`, `ipywidgets` y `pytz`. Requiere Internet y las respuestas del proveedor pueden cambiar. Las celdas usan distintos horizontes e intervalos, así que hay que fijar fecha de descarga, zona horaria y símbolos para comparar ejecuciones.

Los gráficos y métricas son de investigación. Para validar una estrategia harían falta prueba fuera de muestra, costos, deslizamiento, gestión de riesgo y un registro de decisiones reproducible. No usar el cuaderno como consejo de inversión.
